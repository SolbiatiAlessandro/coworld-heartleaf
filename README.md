# Public Heartleaf replay reviews

Static browser viewer for [connections PR #51](https://github.com/Metta-AI/coworld-heartleaf/pull/51), source `394ff6492ef98272f1e89b9a415480db2cfaf903`.

Open `pr-51/394ff64/` to play the real nine-gnome, two-day Claude recording.
The viewer runs entirely in the browser. No model credentials or local server are needed.
The public bundle contains only viewer assets, the recording, its manifest, and the upstream license.

Viewer code comes from the tested PR #51 static build. All 9,120 recorded simulation hashes match. Browser/GPU click-through remains unverified while the review Mac is locked.

The separate `codex/replay-pages` branch publishes via GitHub Pages from its root. Future review versions should use new revision directories so old PR links keep their original viewer and recording. Do not overwrite a revision directory.
